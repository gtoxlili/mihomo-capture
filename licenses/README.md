# Included license texts

`Go-LICENSE` is the Go runtime and standard library license, copied from [Go 1.27.3](https://github.com/golang/go/blob/go1.27.3/LICENSE). Release packages include this text in `THIRD_PARTY_NOTICES.txt` along with licenses and notices read from the Go modules and npm packages used by the build.

These third-party terms are separate from this project's MIT license.
