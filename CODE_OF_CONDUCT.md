# Code of conduct

Discuss technical decisions directly and treat other participants with respect. Criticism of code is welcome. Harassment, threats, discriminatory remarks, sexual attention, and publishing someone's private information are not.

This applies to the project's issues, pull requests, and other project spaces. Do not post captured credentials or another person's traffic as part of a disagreement or a report.

Maintainers may edit or remove harmful content and restrict participation. If you need to report conduct, ask [the maintainer](https://github.com/gtoxlili) for a private contact channel. An issue asking for contact should not identify affected people or include confidential details. Reports are considered in context; no fixed response time is promised.
